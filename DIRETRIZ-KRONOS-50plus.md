# DIRETRIZ KRONOS — Sempre considerar

## Público-alvo: produtores rurais 50+

Toda peça visual da Kronos (boletins, posts, materiais de venda, decks, e-mails)
deve ser desenhada com legibilidade de público maduro em mente. Isso é um pilar
de identidade, não uma exceção.

## Regras práticas de tipografia e contraste

### Tamanhos mínimos

| Elemento                                | Mínimo  | Recomendado |
|-----------------------------------------|---------|-------------|
| Texto corpo (parágrafo, descrição)      | 20px    | 24-28px     |
| Labels secundários (unidade, fonte, eyebrow) | 22px | 26px       |
| Nomes/títulos de item (commodity, seção)| 36px    | 44-48px     |
| Hero/manchete (número grande, headline) | 80px    | 120-220px   |
| Tagline curta                           | 18px    | 20-22px     |
| Botões CTA                              | 16px    | 18-20px     |

Nunca usar abaixo de 16px em qualquer interface clicável.
Nunca usar abaixo de 20px em conteúdo a ser lido.

### Pesos

- Labels pequenos (qualquer texto abaixo de 28px) → SEMPRE Medium (500), nunca Light/Regular
- Texto corpo → Regular (400) ou Medium (500)
- Headings → Light (300) Cormorant para drama editorial, ou Medium (500) Grotesk para impacto sans

### Cores e contraste

❌ NUNCA usar cinza claro #8A8A8A ("soft") como cor de texto sobre cream.
   Não tem contraste suficiente para idade 50+.

✅ Cinza médio mínimo: #4A4A4A ("mid") sobre cream para qualquer label.
✅ Para máxima legibilidade: #3C3C3C ("dark-mid") ou #1A1A1A ("charcoal").

❌ Não usar verde #5C8B4F para texto pequeno — escurecer para #4C7A3C.
❌ Não usar vermelho #AB3C3C para texto pequeno — escurecer para #9F2F2F.

### Ratio de contraste WCAG

Mira em mínimo AAA (7:1) para texto pequeno, AA (4.5:1) para texto grande.
Especialmente: idosos perdem 1-2 níveis de contraste perceptual vs. jovens.

## Aplicação por canal

**Instagram Story / WhatsApp Status (1080x1920)**
- Visto em telinha de celular, distância 30-40cm
- Tudo precisa ser legível em ~360px de altura (preview no feed)
- Nomes de commodity 44-48px mínimo
- Números (preços) 90px+ para dar drama editorial

**Posts feed Instagram (1080x1080)**
- Mais espaço por elemento
- Headline pode ir até 100-140px
- Body 28-32px

**Decks / propostas (1920x1080)**
- Cliente vendo em monitor, distância 60-100cm
- Headings 60-80px
- Body 28-32px
- Nunca colocar texto chave abaixo de 24px

**E-mail (largura ~600px)**
- Body 18-20px (e-mail tem suas próprias convenções)
- Headings 28-36px

```
charcoal      #1A1A1A  (texto principal)
green-night   #081A13  (números, headings em cream)
green         #4C7A3C  (acentos, variação positiva — ajustado para contraste)
gold          #C9A961  (acento decorativo, hover)
mid           #4A4A4A  (labels, cinza mínimo)
dark-mid      #3C3C3C  (labels com mais peso)
red           #9F2F2F  (variação negativa, alerta — ajustado para contraste)
```

## Resumo

Se está com dúvida se algo está pequeno demais ou claro demais: ESTÁ.
Aumente uma faixa de tamanho ou escureça um tom. O público da Kronos não é
designer de 25 anos com Macbook Pro Retina — é produtor rural lendo no
celular sob sol forte ou em casa à noite com vista cansada.
